## 部署与恢复合同

`install-remote-system.sh`、`replace-remote-system.sh` 保留为入口。两个入口现在都要求四个显式参数：暂存目录、候选 APK 的 SHA-256、原钩子或原系统 APK 的 SHA-256、独立校验 DEX 的 SHA-256。摘要须为64位小写十六进制。

部署时把入口和 `remote-system-transaction.sh` 放在同一个 `/data/local/d31-remote/deploy-*` 暂存目录；源码中公共脚本位于 `tools/system-migration/`，不能遗漏暂存复制。目录还需包含 `remote.apk`、`migration-check.jar`；首次安装另需经批准的 `start.sh`、`marker` 和 `install-recovery.sh`。`marker` 内容须为 `1\n`，脚本先做语法检查。以下仅为参数合同，不是本批执行记录：

```sh
sh "$stage/install-remote-system.sh" "$stage" "$candidate_sha256" "$old_hook_sha256" "$checker_sha256"
sh "$stage/replace-remote-system.sh" "$stage" "$candidate_sha256" "$old_system_sha256" "$checker_sha256"
sh "$stage/remote-system-transaction.sh" finalize "$stage" "$candidate_sha256" "$anchor_sha256" "$checker_sha256"
sh "$stage/remote-system-transaction.sh" rollback "$stage" "$candidate_sha256" "$anchor_sha256" "$checker_sha256"
```

写入阶段借用主任务的 `RemoteMaintenance`，拒绝已有更新、手动交接和修复预留。正常停止监督与核心，不强杀。原 APK、系统文件、活动原件和指针、包与组件启用整数、原停止标记均先保存到新建 `backup/`；已有备份拒绝重放。失败恢复使用既有安装适配器恢复真正旧 APK，不再无条件 `pm disable`。恢复前核对第三方安装或系统文件变化，冲突时保留原像并报未完成。

文件写入后重新挂载只读并读取挂载表核验；PM 安装返回后再读取实际安装原件、版本与摘要。这个阶段只报告 `SYSTEM_COMPONENT_STAGED_FINALIZE_REQUIRED`，不能据此宣称系统接替完成。

显式 `finalize` 依次核对系统与特权身份、所需权限、系统文件属性，再恢复原启用状态及控制标记、启动既有监督入口。最后要求活动原件、root 核心进程、对应 APK 或确切缓存映射、新鲜本地健康及 PID 启动时间一致。等待期间释放维护锁。只有各层证据齐全才报告 `INSTALLED_SYSTEM_IDENTITY_AND_CORE_MAPPING_VERIFIED`，仍不包含重启及云端验收。

系统身份缺失为 `SYSTEM_IDENTITY_NOT_VERIFIED`，核心证据不符为 `ATTENTION_CORE_NOT_VERIFIED`。原 APK 与设置恢复并回读后仅报告 `RESTORED_APK_AND_SETTINGS_RUNTIME_NOT_VERIFIED`；未证明旧业务已经运行。任何恢复门失败为 `ATTENTION_ROLLBACK_INCOMPLETE`。原先明确要求停止的设备不会自动清除该意图来凑齐运行验收。

HUP、INT、TERM 使用退出处理尝试恢复；掉电、SIGKILL 和持锁宿主被强杀不保证自动恢复。停止标记按已有文本合同保存，不承诺任意二进制文件恢复；本批不承诺面对恶意并发目录改写的完整文件系统事务。

## 独立只读冒烟入口

`RemoteSystemMigrationCheck.java` 是同包的独立 DEX 入口，不加入正式 APK。父任务需以第三批候选编译类及 Android SDK 编译，D8 使用最低 API23，仅打包该 helper 类，不能重复打包共享平台或维护锁类。运行时 CLASSPATH 包含独立 DEX 和提供这些共享类的完整候选 APK。

```sh
CLASSPATH="$checker_jar:$candidate_apk" /system/bin/app_process /system/bin net.elfradio.d31bootstrap.RemoteSystemMigrationCheck smoke
```

`smoke` 不接受迁移参数、不依赖首次迁移状态或备份、不获取会创建文件的维护锁，不安装、不改权限、不改标签或停止标记。它读取三项真实文件属性、已安装原件和 PM 身份与启用设置、权限授予、当前活动核心及独立进程映射，输出 JSON；缺证据返回非零。当前系统85与活动94无需版本看齐即可做这一只读检查。

标签 setter 只解析签名，报告 `labelSetterResolved` 和 `labelSetterExecuted=false`；其真实设置能力必须在另行批准的写入验收中验证。报告 `snapshotAtomic=false`、`migrationVerified=false`，允许业务继续运行，因此并发更新导致读数变化时只算本次快照缺证据。核心不新鲜或不可见不冒充迁移失败。
