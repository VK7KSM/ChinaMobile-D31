# D31设备取证实现记录

## 2026-09-11：第二批有界采集代码

本批依据主实施计划第11、12节、首批`DiagnosticContract`及`DiagnosticManifest`、首批并行整合验收记录实施。目标是为已冻结的比较合同提供实际文件访问与按需故障文件取证边界，不是全量系统诊断完成。本任务未连接设备，未运行Gradle、Web、提交或发布操作，未修改首批四个诊断类、共享入口、Android清单、版本或构建配置。

### 文件访问和预算

`CollectionAccess`提供以下注入方法：

```java
Stat lstat(String absolutePath) throws IOException
String readLink(String absolutePath) throws IOException
Handle openRegular(String absolutePath, Stat expected) throws IOException
Listing list(String absolutePath, Stat expected, int maximumNames,
    long maximumBytes, long timeoutMs) throws IOException
```

`Handle`提供`stat()`、`read(byte[], offset, length)`和`close()`。`Stat`包含类型、设备号、inode、长度、修改/变更时间、权限和属主；`Listing`包含有界直接子名称、枚举是否真实完成、原因及实际读取字节数。访问实现是可信边界，必须遵守数量/字节/时间参数，不能返回无限列表或以不稳定缓存冒充真实枚举。主采集器还校验返回条目数、字节数、名称合法性及重复名称。

Android实现从根目录开始逐段以`lstat`确认祖先是目录，再用`O_NOFOLLOW | O_NONBLOCK`打开并通过`fstat`复核身份，随后以固定目录描述符的`/proc/self/fd`路径访问叶项。公开SDK没有`O_DIRECTORY`常量，本实现不硬编码架构常量或使用隐藏API。文件读取同样使用`O_NOFOLLOW | O_NONBLOCK`，打开后核对`fstat`与预读取身份一致，只读取普通文件。普通软链接和坏链接只记录目标，不读取目标字节、不递归目标目录。块设备、管道、套接字等不作为普通文件读取；对应项及范围保留未检查或失败状态。

API23没有公开、可移植的有界目录迭代器，因此不使用一次性返回整个目录数组的`File.list()`。实际目录枚举通过调用方指定的BusyBox执行一次性`find`，固定`-mindepth 1 -maxdepth 1 -print0`，不经过shell。目录本身以打开的描述符固定，子进程读取父进程的描述符路径。标准输出按NUL分隔解析，限制名称数、输出字节和单条长度；异常退出、无效UTF-8、无法表达的文件名、缺失工具或访问被拒绝都不能产生完整枚举。子进程结束或超时后关闭流并请求终止，不建立常驻线程或开机监听。

BusyBox指定选项、同UID读取父进程描述符路径及SELinux许可都需要由父任务在授权D31验证；本批没有这项真机结果。工具缺失时明确失败，不回退到无限列表或通过链接访问。文件名含控制字符时首批JSON合同无法表示，本批标记枚举不完整，不拆成多个假文件或静默忽略。

`maxEntries`包含范围根，最小1，最大4096；超过4096的请求参数拒绝。范围实际超过预算时保留已取得的有界前缀，并标为`PARTIAL`及`ENTRY_LIMIT`。4096只是本批合同上限，不是完整D31文件树的规模上限。`maxReadBytes`同时计入文件两轮哈希和目录枚举输出；目录名称返回失败时已消耗字节也必须计入。每个文件还受`maxFileBytes`限制，单批读取最多1吉字节，持续时间最多300000毫秒，目录深度最多64层。根深度为0。

`maxManifestChars`限制结果构建规模，允许16384至首批字符预算减65536；不足以加入下一条时保留现有条目并记录`MANIFEST_LIMIT`。采集器不通过删除`/data`或任意文件来伪造完整性。时间预算使用注入的单调时钟，检测时钟回退和线程中断；有效期采用开始时刻，超时不会刷新快照年龄。

时间限制属于协作式读取预算：每个操作及读取块前后检查；目录子进程另有轮询时限。无法承诺阻塞中的内核元数据调用、文件读取、进程启动或证据`fsync`都能被硬实时中断。故障路径优先保存已取得字节，可能在读取时限结束后完成落盘；索引记录时限是否满足。需要强制外部隔离或更严格总时限时由后续父任务建立执行边界，不能把本批描述为已具备硬实时或全天后台性能验收。

### 稳定性与不完整证据

普通文件要求两轮读取各自完成预期长度，打开后/读后`fstat`与原`lstat`一致，路径回读身份一致，且两轮SHA-256相同。累计预算必须足够两轮完整内容；未读完、文件替换、缩短、权限或身份变化、两轮内容不同均不发布有效文件哈希。Android API23公开`StructStat`的时间字段精度有限，两轮内容对照补充同长度、同时间字段变化检测，但不是锁定文件或原子快照证明。

目录先枚举直接子项，再处理子树，最后再次枚举并核对目录身份和名称集合。子树中任何读取失败、枚举变化、超时、深度或字节上限都会使范围成为`PARTIAL`。局部操作可在不同时间得到稳定值，因此完整枚举也不是同时刻全树原子快照；数据库必须由父任务先取得一致性快照，不能把实时数据库文件哈希当作语义一致证明。

本批不推断`ABSENT`。包括`ENOENT`在内的现场读取失败保留为`READ_FAILED`及明确原因，范围为`PARTIAL`，避免扫描竞争或中断被上层推断成子树不存在。预算未执行项为`NOT_CHECKED`，内容/身份变化为`UNSTABLE`，不与权限失败混淆。无法枚举的未知条目总数不伪造；采集索引`entries`只是实际取得的数量。

已实际采集的是路径、类型、权限、UID/GID、普通文件哈希及链接目标。`selinux`、`xattrs`、`activeSource`、`mountSource`、`activation`本批没有可靠采集适配，逐条明确记为`NOT_CHECKED`。`completeness=COMPLETE`仅表示既定范围的枚举与本批读取闭环完成，不表示所有比较证据已齐；已有比较器仍会因这些字段缺失输出证据不足，测试对此有直接断言。本批不把可见磁盘文件当成实际活动核心，不伪造挂载或启动来源。

独立批次可先调用`validateIndependentScopes`，拒绝重复、父子包含及根目录重叠。各批用不同快照编号保留证据；没有实现跨批去重、同代次冻结、全范围索引核验或聚合器。采集索引固定写入`aggregationStatus=NOT_IMPLEMENTED`、`atomicSnapshot=false`、`systemConsistency=NOT_ASSESSED`。

### 故障取证合同

故障来源类别支持`LOGCAT`、`ANR`、`TOMBSTONE`、`BOOT`、`CUSTOM`。类别只是索引标签，不会自动执行命令、打开默认目录或宣称识别了根因。父任务给出明确文件路径；例如先由其它已批准步骤生成日志文件，再交给本接口。没有来源时不接触文件系统，返回不完整空索引；最多64个来源，重复路径或编号在读取前拒绝。

```java
FaultEvidenceCollector.Source source = new FaultEvidenceCollector.Source(
    "fixture-log", "LOGCAT", "/data/local/tmp/fixture-evidence/logcat.txt");
FaultEvidenceCollector collector = new FaultEvidenceCollector(access, clock);
JSONObject index = collector.collect("fixture-event",
    java.util.Collections.singletonList(source), limits,
    new AndroidEvidenceStore("/data/local/tmp/fixture-evidence/capture"));
```

示例均为非个人测试路径，不是内置默认来源。存储目录由父任务预建并控制访问权限。`AndroidEvidenceStore`排他创建0600新文件、拒绝祖先/叶链接、写入并同步；不覆盖旧文件，不删除失败原件，不创建用户目录，不部署或修改系统文件。调用方须将返回索引另行保存为不可变原件；本类不自动保存索引或上传。

每个来源最多在内存中保存1兆字节前缀，还同时受总字节和单文件预算限制。索引记录源路径/类别、采集时刻、原始状态、偏移、实际取得字节、取得字节SHA-256、存储引用/长度/摘要、截断或失败原因。存在且确认为空的文件保存0字节原件并记录空摘要；读取失败不能用0字节假原件替代。原始日志正文不进入JSON索引。

故障取证检查读取前后的路径及打开文件身份；变化时仍保存已经取得的字节，但标记`UNSTABLE`。只取得前缀时标记`TRUNCATED`，摘要明确属于该前缀，不能用于源文件完整哈希。读取中途失败或超时也优先保存现有前缀，下一来源因预算不足记为未检查。保存失败时记录`STORE_FAILED`和尝试的原件名，`storedBytesKnown=false`，不猜测部分写入后磁盘上有多少字节。

可注入`FaultEvidenceCollector.Store.storeNew(artifactId, byte[])`替代实际存储；其回执必须返回原件引用、字节长度和SHA-256，采集器会检查长度与摘要相符。该接口是受信任的持久化边界，必须排他创建和保留失败现场，不能用返回成功代替真实落盘。磁盘满、同步失败、进程被杀后的索引续接仍需实际设备及后续持久化编排验证。

默认不读取用户消息、账号、凭据或身份路径。原始logcat、ANR等仍可能包含敏感正文，父任务必须限制来源并按私有证据保存，不能直接复制进公开文档或仓库。本模块不是内容脱敏器；不通过吞掉正文或假装空日志来换取公开安全，也不自行读取任何默认账号数据库。
