## 公共接口与接线

包名为 `net.elfradio.d31bootstrap.management`。精确入口为：

```java
public static ContactsNexui.Snapshot ContactsNexui.read(
    Context context, String source, SystemManagement.Control control) throws Exception;

public JSONObject ContactsNexui.Snapshot.page(
    int offset, int limit, SystemManagement.Control control) throws Exception;

```

调用者必须位于已授权D31的API23 root进程工作线程，进程的主Looper必须真实运行以派发 `ServiceConnection`。传入已有取消控制器；只读路径不调用 `Control.before`。独立命令自行初始化系统Context、在工作线程读取并运行主Looper，避免独立 `app_process` 主线程等待导致绑定回调无法派发。

`source` 只接受上述五个准确枚举名，每次只请求一个来源。不合并来源、不伪造统一编号，不把原厂 `mId/mLookup/mNumbers` 转换成Android号码行。记录保留原厂JSON字段；未知字段不向元数据泄露。企业组织树、会议导航、照片和按lookup详情不在本次 `all_contacts` 列表范围。

生产适配器固定组件，核对包管理器中的组件归属、启用与导出状态。只使用 `bindService` 的 `flags=0`，不使用 `startService` 或 `BIND_AUTO_CREATE`，不注册持续观察器，不发送 `isManual/ownerCode/request_code` 或联系人写命令。服务未运行、拒绝绑定、断开、超时均明确失败或不完整，不能空列表成功。绑定后只发送一次，重连不自动重放；每次使用新的应答Messenger。单进程最多一个活跃采集，跨进程串行由主任务调度负责。

读取退出前解绑、清除接收队列、终止并最多等待1秒确认接收线程退出。解绑或线程退出未确认时抛出异常，不返回成功快照。取消在等待中最多每50毫秒检查一次，在页消费中逐项检查；不能承诺同步框架绑定/解绑调用、当前分片解析或Binder内部异常阻塞立即可取消。

主任务持有同一 `Snapshot` 进行分页，使用完毕必须关闭。快照不持久化，不自动放入全局缓存，不跨进程恢复。进程丢失后应重新读取并产生新的 `snapshot_id`，禁止沿用旧页偏移拼接新列表。现有 `contacts_read` 仅空参数且Web会丢弃来源扩展字段，本批未接入或改变该合同；公共任务接线、快照生命周期、私有内容持久化与展示来源由主任务单独处理，不能默认为原厂已获得统一Web管理能力。

## 预算、完整性与回执

- 每次采集等待预算8000毫秒，使用单调时间。迟到结束帧也受截止时间校验；不因接近上限或源不变自动加预算。
- 最多128分片、4096记录、单片131072输入字符、累计1048576输入字符。单记录规范化JSON最多8192字符；原生字符串、临时解析对象和规范化记录仍有有限额外内存，输入字符预算不是进程RSS保证。
- JSON嵌套最多16层；非数组、非对象条目、错误类型、尾随内容、未知来源/动作/状态、重复开始或未开始的进行帧均拒绝。协议错误清空之前记录，不能暴露先前行并冒充成功。
- 接受新独立应答通道上的单独结束帧，符合冻结客户端在空缓存直接追加并结束的消费路径，元数据仍记录 `start_observed=false`。只有实际见到结束且未超预算才有 `list_complete=true`。
- 分页 `limit=1..32`，每页条目JSON不超过12000字符，加固定元数据低于16000字符。页偏移只针对当前快照，至少一条符合单记录预算的记录能前进；不在每页重新查原厂服务。
- `RECORD_LIMIT/TEXT_LIMIT/FRAME_LIMIT/RECORD_SIZE_LIMIT/TIMEOUT` 保留已接受的有限记录，但 `ok=false/list_complete=false`。`page_complete` 只表示本快照中已保留记录已翻完，不能覆盖 `list_complete=false`。
- 原厂协议没有独立总数、分片编号或全局快照世代。本批不臆造去重或原子快照保证，明确 `snapshot_consistency=NOT_PROVIDED_BY_VENDOR`。不同来源可能重叠，不合并或删除重复原厂记录。

`metadata()` 的固定字段包括：`ok/read_only/source/owner_package/contact_type/snapshot_id/status/sampled_at_ms/elapsed_ms/record_count/frames_received/received_chars/start_observed/end_observed/list_complete/contact_values_emitted/completion_scope/all_sources_complete/snapshot_consistency/android_equivalence/service_implementation` 及预算。`completion_scope=SELECTED_SOURCE_ALL_CONTACTS_REPLY`、`all_sources_complete=false`、`service_implementation=NOT_DECRYPTED` 始终明确范围；不输出联系人记录、值摘要或异常原文。

`page()` 另加 `items/offset/next_offset/has_more/page_complete/cursor_scope`，会包含个人内容，不能用于公开日志。修改返回JSONObject不会改变后续分页结果；关闭后任何元数据或分页访问都失败。
