## 使用音量加键进入Recovery

此方式要求已经安装包含该入口的1.4.0固件，并且设备仍能启动内核、挂载system和data、运行早期开机脚本。它不是原厂BootROM快捷键，不能处理引导器、内核或入口文件本身损坏。

1. 断开D31电源。
2. 按住机身正面的音量加键，再接通电源，持续按住约30秒。老机器按键可能接触不良，应按实按钮内侧。
3. 松开后等待。检测到按键后，设备会自动再次重启并进入Recovery；可能先短暂出现桌面，再重启进入菜单。
4. 在Recovery内，用音量减键向下移动菜单，短按免提键确认。这两个操作已经由用户实机确认。
5. 只想退出时选择`reboot system now`，短按免提键。不要选择擦除数据或安装更新菜单进行按键测试。

入口带防循环保护：请求Recovery后，下一次正常启动会暂时忽略触发，系统启动完成后重新准备下一次检测。不要连续拔电或长按免提键强制重启干扰检测。

## 卡刷与写入范围

已验证的是进入Recovery、菜单操作和正常退出；没有对这台唯一设备执行本版完整刷写或离线恢复验收。Windows工具的卡刷位置仍是预留项，本次没有把未验证的卡刷功能开放成按钮。

本包写入system、预装应用所在的userdata和独立logo图片分区；不写boot、Recovery、设备身份或校准分区。安装器在写入前逐字核对现有boot与已知基线，不匹配就拒绝继续。logo分区先核对容量和载荷校验，再写入并逐字读回。

如果system或data已损坏到早期开机脚本不能运行，音量入口和8765均可能不可用；原厂uptool同样依赖内核及网络服务运行。本项目不能保证这种情况下不拆机救回。
