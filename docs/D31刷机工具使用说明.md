# D31刷机工具使用说明

## 正式刷机

1. 解压`D31_SVP3390_Windows_Flash_Tool_v1.4.8.zip`，保持目录结构不变。v1.4.8支持中文用户名和中文目录，固定使用D31专用ADB服务器端口5042，并在启动时清理该端口的旧服务和旧设备连接；不会干扰Pixel 3使用的5041端口或H13使用的5038端口。GitHub公开下载不需要账号或Token；工具不读取电脑上的aria2配置，源站限制多连接时会自动保留断点并切换到单连接兼容模式。
2. 双击`D31-Flash-Tool-v1.4.8.exe`。
3. 在IP框中填写准备管理的D31地址，点击“连接ADB”。IP不是自动发现结果；有多台D31时，填写哪台的IP就连接哪台。连接成功后工具会立即识别设备，“检测D31”用于手动刷新状态，“断开ADB”用于断开当前目标并切换到另一台设备。
4. 点击“只读检查”。该检查不需要先下载刷机包，只读取root、构建、网络、分区尺寸、Recovery入口、空间和依赖，不修改或重启设备。通过Wi-Fi地址可以管理和只读检查，但不能开始刷机。
5. 点击“选择刷机包”选择已经下载的官方ZIP，或点击“GitHub高速下载”或“Cloudflare高速下载”。两个按钮均使用工具内置的aria2 1.37.0执行多连接下载和断点续传；GitHub最多8个连接，Cloudflare最多16个连接。GitHub公开Release下载不需要账号或Token。状态栏会实时显示来源、已下载量、总量、百分比、实际连接数、速度和预计剩余时间。
6. 等待1.32GB固件通过固定长度和内置SHA-256校验。设备连接、只读检查和刷机包选择可以任意先后。
7. 正式刷机前必须插好网线，并确保工具连接的是D31有线`eth0`的IP；如果当前使用Wi-Fi地址，应先点击“断开ADB”，改填有线IP后重新连接并执行只读检查。
8. “刷机前自动备份原系统到电脑硬盘”默认勾选，但可以取消。备份不是强制要求，正常刷机也不需要插U盘或TF卡。
9. 勾选清空数据确认框，点击“开始刷机”。只有设备只读检查、刷机包校验和有线地址三项同时通过时，该按钮才可操作。
10. 如果保留默认备份选项，工具先把该机的原系统保存到工具目录下的`D31备份`，完成后自动继续刷机。如果取消备份，工具显示风险提示，确认后直接刷机。
11. 刷机开始后，D31会自动重启。不要断电、乱按实体键、关闭刷机窗口，也不要让电脑休眠或关机。首次启动会重建`userdata`并进行ART优化，明显变慢属于正常现象。

## 备份保存在哪里

- 备份保存在运行刷机工具的电脑硬盘，不写入U盘或TF卡。
- 每次勾选备份都会为当前连接的D31创建独立目录，不判断这是第几次刷机。
- 急救包只适用于创建它的那台D31，不能用于其他设备。
- 急救包不包含`userdata`，因此不包含SIP、邮箱、Telegram、Zello、Wi-Fi账号、密码、通信录或邮件。
- “禁止公开的本机私有备份”包含设备身份和校准分区，只能保存在电脑上，禁止上传或分享。

## 刷坏后的恢复

只有D31刷机后无法启动、但原厂Recovery仍能进入时，才需要U盘或TF卡：

1. 在电脑的`D31备份`中找到这台D31的急救包。
2. 将TF卡或U盘格式化为FAT32。
3. 把`需要抢救时复制到TF卡或U盘`目录及全部文件原样复制到介质。
4. 给D31保持稳定供电，插入介质并进入原厂Recovery。
5. TF卡选择`Apply update from SD card`；U盘选择Recovery显示的USB OTG入口。
6. 选择`D31_RESCUE_UPDATE.zip`。校验通过后，程序恢复这台D31原来的`system`和`boot`。
7. 显示`D31 emergency restore completed`后选择`Reboot system now`。
8. 如果显示`ERROR 22`，返回Recovery主菜单，手动执行`Wipe data/factory reset`后重启。

如果刷机时取消了备份，电脑中不会生成本机急救包，也就不能使用上述恢复流程。

## 全新原厂D31打开ADB

1. 在原厂拨号键盘输入`*#233#*`并按绿色拨出键，进入Android系统设置。
2. 如果没有“开发者选项”，进入“关于设备”，连续点击“版本号”7次，然后打开“USB调试”。
3. 在“安全”中打开“未知来源”，再打开蓝牙并与Windows电脑配对。
4. 输入`*#223#*`并按绿色拨出键，进入Android原生桌面。
5. Windows运行`fsquirt`，把`首次引导工具\D31-wireless-adb-v1.0.apk`通过蓝牙发送给D31。
6. 在原生桌面接受文件并安装。安装后点击“打开”，再点击“开启无线ADB（端口5555）”。

刷机只使用D31的有线网络地址。应用名称虽然是“无线ADB”，但TCP端口5555同样可以通过有线网络访问。

## 当前验证边界

Windows工具和急救入口已完成离线构建、哈希和故障注入检查。项目当前只有一台D31，因此没有执行真实Recovery刷写，也不能宣称卡刷恢复已经完成真机验收。

本版v1.2.0刷机包使用从母机只读获取并物理精简的完整`system`镜像，不再依赖刷机后的临场卸载。学习强国、WPS、TR-069、EMU、旧浏览器等18个路径已经从镜像中删除；原厂SIP电话、Nexui、中文输入法、计算器、屏保及工程测试组件保留。包内同时包含TLS 1.2、网络切换重注册、Firefox和Telegram主页入口、时钟、实体键、Zello守护、无线ADB和动态入站防火墙等已验收优化，并新增双通道短信程序、定制文件管理器以及U盘和TF卡动态识别、独立显示与插入弹窗，但不包含任何用户账号或配置。该包尚未在备用D31执行真实Recovery刷写。

高速下载的并发数是上限而不是必须维持的连接数。服务器拒绝分段或暂时限速时，aria2会按照可用连接继续并进行退避重试；下载中断后会保留临时文件和`.aria2`断点记录，再次选择任一高速下载按钮即可继续。完整ZIP下载结束后仍必须通过工具内置的固定长度和SHA-256校验，网络加速不会降低刷机包验证标准。实际最高速度仍受本地宽带、跨境路由、GitHub或Cloudflare节点负载限制。
