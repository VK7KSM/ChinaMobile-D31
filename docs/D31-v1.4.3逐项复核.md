## 音量加进入Recovery

保留现有音量加激活方式：断电后按住D31机身音量加，再通电并持续按约30秒，松开后等待自动重启进入Recovery，期间可能短暂出现桌面。老机器按键需要按实。

已测试音量减向下移动菜单、短按免提键确认；查看日志后可通过`back`返回，选择`reboot system now`正常重启。

此入口依赖已安装的早期系统组件、可运行的内核和Recovery，不是boot损坏后的硬件级救砖保证。本安装器写入system、logo并清空data，不写boot或Recovery；Windows卡刷按钮仍为预留项。
