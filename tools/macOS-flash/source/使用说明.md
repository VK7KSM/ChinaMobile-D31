# D31 刷机工具 macOS 命令行版

给 macOS 用的最小刷机工具：下载签名刷机包，把它刷进 D31。刷机逻辑与 Windows 图形版**共用同一份后端脚本**，行为一致。

## 使用前提

- **D31 必须插网线。** 刷机会清空 userdata，Wi-Fi 密码随之消失；只有有线才能在重启后自动回到网上，让工具完成最后的校验。
- **Mac 用什么上网都行**，Wi-Fi 即可，只要和 D31 在同一个局域网。Mac 不需要网口，也不需要转接头。
- D31 上的 ADB 已经打开，能用 `IP:端口` 连上。

## 运行

```bash
bash d31-flash.sh --device 192.168.2.62:5555
```

首次运行会自动补齐两个运行时，之后跳过：

| 运行时 | 来源 | 体积 |
| --- | --- | --- |
| PowerShell 7 | 微软官方免安装包，校验官方 SHA-256 | 约 68 MB |
| adb | 谷歌官方 platform-tools，原生 arm64 | 约 16 MB |

两者解压到工具目录下的 `runtime/`，**不需要 brew、不需要 sudo、不写任何系统目录**。系统里已经装过 `pwsh` 或 `adb` 就直接用现成的。用 curl 下载不带隔离标记，Gatekeeper 不会拦。整个工具目录删掉即可彻底清除。

## 常用参数

| 参数 | 说明 |
| --- | --- |
| `--device <IP:端口>` | 必填，D31 的**有线**地址与设备侧 ADB 端口 |
| `--preflight-only` | 只做只读检查，不写设备任何分区 |
| `--package-path <路径>` | 用已经下好的刷机包，不再下载 |
| `--source cloudflare` | 从 Cloudflare 取包，默认走 GitHub |
| `--yes` | 跳过“会清空全部数据”的二次确认，无人值守时用 |

刷机包约 1.7 GB，下载支持断点续传：中断后重跑同一条命令会从断点继续，不会重头再来。

## 它做什么，不做什么

**做**：取包并校验 SHA-256、连接设备、核对 root 与构建指纹、核对分区尺寸与 Recovery 入口、分块续传上传并逐块校验、写 Recovery 命令、重启刷写、等设备回来后核对结果。

**不做**：图形界面、原厂 uptool 救砖通道、刷机前备份。备份省掉的风险有限，因为安装器本来就不写 `nvram`、`nvdata`、`protect1/2`、`proinfo` 这些身份与校准分区。要备份请用 Windows 图形版。

## 出问题时

- **下载中断**：重跑同一条命令，自动续传。
- **提示地址不属于 eth0**：D31 没插网线，或者你连的是它的 Wi-Fi 地址。插网线，用有线 IP 重连。
- **触发 Recovery 之后**：不要断电、不要拔网线、不要让电脑休眠。设备会自己刷完并重启，工具在等它回来。
- **macOS 提示“本地网络”权限**：必须允许，否则连不上局域网里的 D31。

刷机失败导致设备无法启动时，用 Windows 图形版里的救砖功能。
