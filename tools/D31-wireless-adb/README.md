## 两个端口的区别

| 端口 | 用途 |
| --- | --- |
| `5555` | Android的adbd服务，电脑用ADB连接 |
| `8765` | 独立root命令与状态服务，不需要adbd运行 |
| 电脑`5042` | D31专用ADB服务器，不是D31的监听端口 |

开发版8765仅接受私有局域网及本机来源，不设密码、令牌或固定电脑白名单。能访问此端口的局域网设备可以读写文件和执行root命令；不要映射到公网。请求与输出可能包含私人内容，只留在设备本地，不上传公共服务。

## 不用ADB执行命令

电脑安装Python 3后，在客户端所在目录运行，替换示例IP：

```powershell
python rescue_client.py 192.168.1.20
python rescue_client.py 192.168.1.20 "id"
python rescue_client.py 192.168.1.20 "getprop sys.boot_completed"
python rescue_client.py 192.168.1.20 "setprop service.adb.tcp.port 5555; setprop ctl.start adbd"
```

随后连接ADB；如旧连接显示offline，只断开同一D31，不要终止其他设备的ADB服务器：

```powershell
adb -P 5042 disconnect 192.168.1.20:5555
adb -P 5042 connect 192.168.1.20:5555
adb -P 5042 -s 192.168.1.20:5555 shell id
```

### HTTP接口

| 接口 | 内容 |
| --- | --- |
| `GET /health` | 版本、版本代码、真实UID、忙闲和系统运行毫秒 |
| `GET /` | 状态缓存，包含缓存生成时间；不会等待现场root查询 |
| `POST /exec` | JSON：`{"id":"唯一任务号","command":"id","timeout":30}` |
| `GET /jobs/唯一任务号` | 状态、输出、退出码、耗时和截断标志 |

写请求需要`Content-Type: application/json`及明确长度，不接受浏览器`Origin`或分块请求。只接受一条执行中的命令；忙时409。同任务号、同参数返回原任务，不重复执行；同号不同参数409。保留最近32项，过期后不要复用旧任务号。

默认超时30秒，上限120秒；命令最多8192字节，请求最多16384字节，合并输出最多65536字节。超时会清理普通同进程组子进程，不能撤销已写入的文件，也不能保证终止主动脱离进程组的程序。`completed`表示命令结束，是否成功还要检查`exit_code`。

设备任务记录在`/data/local/d31-rescue/jobs/`。服务重启后未完成任务标为中断，不自动重放。电脑客户端不在网络错误后擅自重新提交命令。

## 开机与卸载边界

普通APK仍保留原有广播启动服务。打开应用后，先点击“启动/检查命令探针（8765）”，确认成功，再点击“启用开机救援（8765）”。它向`/system/bin/install-recovery.sh`加入独立后台入口，保留原文件备份、原权限及标签，恢复system只读。安装APK本身不会自动修改启动文件。

该入口已在本项目D31上经过两次正常重启验证。第二次开机约23秒时，APK和Nexui尚未运行，8765已经能执行root命令；约38秒时系统完成启动。这证明服务不依赖桌面、APK进程或ADB，不表示能覆盖所有启动故障。

独立服务仍依赖可读的data分区及Android运行时，不能修复引导器、存储芯片或所有启动故障。原厂`uptool`以太网入口是另一路兜底，不需要重复装进APK，参见[以太网恢复教程](../../docs/D31以太网救援.md)。

实际卸载APK后，已验证启用标记删除、独立进程退出、8765监听消失。遗留启动脚本先检查该标记，没有标记便退出；未实测“卸载后再次重启”，不把静态检查当作该项验收。救援日志和启动脚本备份仍留在`/data/local/d31-rescue/`，卸载APK不会删除这些文件。

**更新请直接覆盖安装，不要先卸载。** 卸载重装可能改变应用UID，而已加固设备的原厂root套接字仍授权旧UID；本次重装遇到该问题，通过现存ADB将管理组迁移到新UID后恢复。需要重新授权时应读取实际UID，不能照抄其他设备的数值，也不应把套接字权限改成所有应用可写。全新原厂系统与卸载重装不是同一条件。

## 从源码构建

需要JDK 17、Android SDK 34；Gradle包装器会下载所需依赖。在`source`目录配置SDK路径，然后运行：

```powershell
./gradlew.bat testReleaseUnitTest assembleRelease lintRelease
```

发行签名通过环境变量`D31_SIGNING_KEYSTORE`、`D31_SIGNING_STORE_PASSWORD`、`D31_SIGNING_KEY_ALIAS`、`D31_SIGNING_KEY_PASSWORD`提供。仓库不包含私钥；自行签名的APK无法覆盖不同签名的现有安装。不要为解决签名冲突随意卸载正在承担救援功能的管理应用。

HTTP解析采用NanoHTTPD 2.3.1，遵循其BSD许可；JUnit与org.json仅用于桌面测试。项目原有ADB、USB、网络及本地急救代码随同一个APK源码一起保留，本轮未开发Windows刷机工具。
