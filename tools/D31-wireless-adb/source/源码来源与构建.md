# 2026-09-13 固件1.4.4配套源码

本目录同步D31管理应用基础版169、完整版170及独立 `systemSupport 1.1.0` 的源码，配套Windows工具版本为1.6.7。这里的应用版本名仍为 `1.34.6-candidate`，不能将固件1.4.4误写为APK版本。

## 来源及范围

- 来源工作区相对路径为 `research/d31_adb_bootstrap/`。应用的256份 `app/src/main/java` 文件已与169/170构建目录生成的源码逐字比对，全部一致；`source-files.json`记录本次每项公开副本的来源、长度和SHA-256。
- 同步 `app/src` 中的生产源码、资源及正式测试、根构建配置、Gradle包装器，以及 `systemSupport` 的源码和既有C辅助程序。正式测试中的固定脱敏夹具仅保留合成身份，不是设备原始捕获；原始日志、临时测试输出和主机私有回放数据没有同步。
- 不复制旧PTT实验、工作区开发日志、设备标识、真实账号、私钥、签名文件、凭据、依赖缓存、`node_modules`、编译中间物或其他未经审查的研究文档。已有三个8765客户端/验核脚本保留，使用者必须显式提供目标地址。
- `isrgrootx1.pem`为公开根证书，`update-public.pem`为更新验签公钥，均是运行所需公开资源；不包含对应私钥。
- 本目录 `.gitattributes` 增加原始字节保留规则，脚本及标记仍采用LF；`gradlew`仅将CRLF规范为LF以便类Unix系统直接运行。除这些发布副本适配及说明/许可文件外，同步源码保持来源字节。

## 构建

需要JDK17、Android SDK34、Gradle8.9；Android Gradle插件为8.7.3。通过 `ANDROID_HOME` 或本机未跟踪的 `local.properties` 配置SDK。

在本目录执行：

```powershell
./gradlew.bat :app:assembleBasicRelease :app:assembleFullRelease -PremoteBaseVersionCode=169 -PremoteVersionName=1.34.6-candidate
./gradlew.bat :app:testBasicReleaseUnitTest :app:testFullReleaseUnitTest -PremoteBaseVersionCode=169 -PremoteVersionName=1.34.6-candidate
./gradlew.bat :systemSupport:testDebugUnitTest :systemSupport:assembleDebug
```

基础版只依赖NanoHTTPD；完整版另含Paho MQTT、Java-WebSocket、WebRTC及其传递依赖。准确坐标以 `app/build.gradle` 为准，WebRTC固定为 `io.github.webrtc-sdk:android:125.6422.07`，完整版ABI为 `armeabi-v7a`。首次构建需从配置的公开仓库取得依赖；只有本机缓存完整时才能使用 `--offline`。本次源码同步没有重新运行整包构建，不将既有构建结果冒称公开目录的新构建验收。

应用构建参数不可省略：脚本默认保留旧开发序号，不会自动产生169/170。`systemSupport/build.gradle`固定版本代码6、版本名1.1.0，生产包名为 `net.elfradio.d31system`。

另保留双制品构建/验包入口 `tools/Build-RemoteVariants.ps1`，默认 `-Mode Static`仅进行本地源码静态检查。本次在公开副本执行该静态入口已通过。其Build/Verify分支锁定项目正式证书指纹，不适用于任意自签名制品；没有修改该合同，也没有公开正式签名材料。

正式应用签名通过 `D31_SIGNING_KEYSTORE`、`D31_SIGNING_STORE_PASSWORD`、`D31_SIGNING_KEY_ALIAS`、`D31_SIGNING_KEY_PASSWORD`环境变量从本机提供，源码中没有变量的实际值。缺少签名时管理应用release产物未签名；`systemSupport:assembleRelease`需要完整签名配置。调试构建或自行签名不保证可以覆盖正式包，`systemSupport`的系统权限也不能由普通调试安装替代。

源码及依赖版本可审查，不承诺APK与正式签名制品逐字一致。NDK、JDK、依赖缓存、签名及打包元数据都可能影响二进制结果。`systemSupport`目录保留的 `guard.c`、`local_actions.h`、`PackageState.java`及 `start.sh`供独立支持程序来源审查；本目录不包含本轮完整固件装配、系统补丁、安装路径布局或OAT生成流程，不把这些源码等同于完整固件的可复现构建。
